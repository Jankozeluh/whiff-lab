# Whiff Lab

Open baseball models built only from free, openly licensed data, in the look of [The Daily Whiff](https://thedailywhiff.com).

First project: **What are the odds?** A win probability model for any game state (inning, outs, runners, score, era), learned from a century of play-by-play, with the historical games behind every number.

Work in progress.

## Data

- [Retrosheet](https://www.retrosheet.org): play-by-play and game logs.
- [Lahman Baseball Database](https://sabr.org/lahman-database/): season statistics, CC BY-SA.
- [Chadwick Register](https://github.com/chadwickbureau/register): player identifiers, ODC-By.
